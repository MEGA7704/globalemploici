1. Déployer l’intégralité du dossier `dist/` sur Cloudflare Pages.
2. Aucune nouvelle migration D1 n’est nécessaire pour la V39.

4. Les fichiers DOCX de référence sont disponibles dans `dist/legal/`.

La V39 ne modifie ni les routes privées ni les liaisons de données V31+ stabilisées.
