CONDITIONS GÉNÉRALES D’UTILISATION DE GLOBAL EMPLOI

Dernière mise à jour : 9 août 2026

PRÉAMBULE

Les présentes Conditions Générales d’Utilisation, ci-après désignées « CGU », ont pour objet de définir les règles d’accès et d’utilisation de la plateforme numérique GLOBAL EMPLOI.

GLOBAL EMPLOI est une plateforme de mise en relation professionnelle destinée notamment aux demandeurs d’emploi, travailleurs, professionnels de métiers, candidats, recruteurs, entreprises et organisations.

La plateforme permet notamment :

La création d’un compte Demandeur ou Recruteur ;
La création et la gestion d’un profil professionnel ;
La consultation et la recherche d’offres d’emploi ;
La consultation et la recherche de talents ;
La publication d’offres ;
L’envoi et le suivi de candidatures ;
L’envoi et la réception de propositions de recrutement ;
La messagerie entre utilisateurs ;
La réception de notifications ;
Le contact avec le support GLOBAL EMPLOI ;
La souscription à des formules d’abonnement ;
La gestion et la vérification de certains comptes recruteurs.

Toute utilisation de GLOBAL EMPLOI implique le respect des présentes CGU.

Les opportunités proposées peuvent notamment concerner :

Les emplois ;
Les contrats ;
Les stages ;
Les missions ;
Les prestations ;
Les travaux professionnels ;
Les recrutements ponctuels ;
Les collaborations professionnelles.

GLOBAL EMPLOI agit essentiellement comme plateforme technique de mise en relation.

Sauf mention expresse contraire, GLOBAL EMPLOI n’est ni l’employeur du candidat, ni le salarié du recruteur, ni partie au contrat conclu directement entre les utilisateurs.

Lorsque l’utilisateur ne dispose pas lui-même de la capacité juridique nécessaire, l’utilisation de certains services doit être effectuée avec l’autorisation ou l’intervention du représentant légal lorsque celle-ci est requise.

GLOBAL EMPLOI permet à tout visiteur d’accéder à certaines fonctionnalités publiques sans disposer d’un abonnement payant.

Filtrer les résultats ;
Consulter les profils publics autorisés ;
Rechercher des talents ;

Certaines actions professionnelles nécessitent toutefois l’âge requise, la création d’un compte et, lorsqu’elle est prévue, l’activation d’une formule d’abonnement appropriée.

ARTICLE 5 — CRÉATION D’UN COMPTE

GLOBAL EMPLOI propose notamment deux catégories principales de comptes.

5.1. Compte Demandeur

Le compte Demandeur est destiné notamment au (18 ans +):

Aux demandeurs d’emploi ;
Aux travailleurs ;
Aux professionnels de métiers ;
Aux artisans ;
Aux indépendants ;
Aux prestataires ;
Aux candidats recherchant une mission, un emploi ou un contrat.

5.2. Compte Recruteur

Le compte Recruteur est destiné notamment :

Aux entreprises ;
Aux employeurs ;
Aux organisations ;
Aux structures professionnelles ;
Aux personnes habilitées à rechercher légalement un travailleur ou un prestataire.

5.3. Informations obligatoires

L’utilisateur s’engage à fournir des informations :

Exactes ;
Actuelles ;
Complètes ;
Sincères ;
Non trompeuses.

Il est interdit d’utiliser l’identité d’une autre personne, d’une entreprise ou d’une organisation sans autorisation.

ARTICLE 6 — SÉCURITÉ DU COMPTE

Chaque utilisateur est responsable de la confidentialité de ses identifiants.

Le mot de passe est strictement personnel.

Il est interdit :

De partager volontairement ses identifiants avec une personne non autorisée ;
D’utiliser le compte d’une autre personne sans permission ;
D’usurper l’identité d’un utilisateur ;
D’usurper l’identité d’une entreprise ;
De tenter d’accéder illicitement au compte d’un tiers ;
De contourner les dispositifs de sécurité de global emploi.

GLOBAL EMPLOI peut invalider une ou plusieurs sessions lorsqu’une action de sécurité le justifie.

L’utilisateur doit signaler au support toute utilisation suspecte de son compte.

ARTICLE 7 — PROFIL DU DEMANDEUR

Seul le Demandeur âgé de 18 ans + peut créer un profil professionnel contenant notamment :

nom et prénom ;
métier ou profession ;
compétences ;
expériences professionnelles ;
niveau d’études ;
qualifications ;
localisation ;
disponibilité ;
CV ;
informations utiles au recrutement.

Le Demandeur est seul responsable de la véracité des informations publiées.

Sont notamment interdits :

Les faux diplômes ;
Les fausses expériences ;
Les faux cv ;
Les documents falsifiés ;
L’utilisation de l’identité professionnelle d’une autre personne.

ARTICLE 8 — PROFIL DU RECRUTEUR

Le Recruteur peut renseigner notamment :

Le nom de l’entreprise ;
Sa raison sociale ;
Son secteur d’activité ;
Son adresse ;
Ses coordonnées ;
Son logo ;
Sa présentation ;
Ses informations professionnelles ou administratives.

Le Recruteur garantit qu’il dispose des autorisations nécessaires pour agir au nom de l’entreprise ou de l’organisation qu’il représente.

GLOBAL EMPLOI peut demander des informations ou documents complémentaires dans le cadre d’une procédure de vérification.

ARTICLE 9 — PUBLICATION DES OFFRES

Le Recruteur autorisé peut publier des offres conformément aux droits associés à son compte.

Chaque offre doit correspondre à une opportunité réelle.

Une offre peut notamment préciser :

L’intitulé du poste ;
Les missions ;
La localisation ;
Le type de contrat ;
Les qualifications recherchées ;
L’expérience demandée ;
La rémunération lorsqu’elle est communiquée ;
Les modalités de candidature.

Sont interdites notamment :

Les offres fictives ;
Les offres frauduleuses ;
Les annonces destinées à escroquer les candidats ;
Les annonces mensongères ;
Les activités manifestement illicites ;
Les annonces usurpant le nom d’une entreprise ;
Les offres destinées uniquement à collecter abusivement des données personnelles.

GLOBAL EMPLOI peut masquer, suspendre ou retirer une offre en cas de violation des présentes conditions.

ARTICLE 10 — CANDIDATURES

Le Demandeur disposant des droits nécessaires peut postuler à une offre.

Une candidature peut connaître différents statuts tels que :

Envoyée ;
En cours d’examen ;
Acceptée ;
Refusée ;
Annulée ;
Retirée.

Le Demandeur peut, lorsque la fonctionnalité est disponible :

Annuler sa candidature ;
Réactiver une candidature annulée ;
Retirer une candidature.

Une candidature retirée peut disparaître des espaces opérationnels du Demandeur et du Recruteur tout en pouvant être conservée dans les données administratives nécessaires au fonctionnement, à la sécurité ou à la traçabilité de la plateforme.

Lorsque le système l’autorise, un Demandeur ayant retiré une candidature peut présenter ultérieurement une nouvelle candidature à la même offre.

L’envoi d’une candidature ne garantit pas une embauche.

ARTICLE 11 — PROPOSITIONS DE RECRUTEMENT

Un Recruteur autorisé peut transmettre une proposition professionnelle à un Demandeur.

Le Demandeur peut notamment :

Consulter la proposition ;
L’accepter ;
La refuser ;
La supprimer ou la masquer de son propre espace lorsque cette fonction est disponible.

Le Recruteur peut également retirer ou masquer certaines propositions de son propre espace.

La suppression locale d’une proposition par un utilisateur ne signifie pas nécessairement sa suppression des données administratives de GLOBAL EMPLOI.

Une proposition de recrutement ne constitue pas automatiquement un contrat de travail ou une garantie d’embauche.

Les conditions définitives doivent être établies directement entre le Recruteur et le Demandeur.

ARTICLE 12 — MESSAGERIE

GLOBAL EMPLOI peut proposer une messagerie permettant les échanges professionnels entre utilisateurs.

Les utilisateurs peuvent notamment, selon les fonctions disponibles :

Envoyer des messages ;
Recevoir des messages ;
Consulter leurs conversations ;
Masquer ou supprimer un message de leur propre espace ;
Masquer ou supprimer une conversation de leur propre espace.

Une suppression effectuée depuis l’espace personnel d’un utilisateur peut constituer uniquement un masquage local.

Elle n’oblige pas GLOBAL EMPLOI à supprimer immédiatement la donnée de ses systèmes administratifs lorsque sa conservation reste nécessaire pour :

La sécurité ;
La gestion des litiges ;
La lutte contre la fraude ;
L’audit ;
Le support ;
Le respect d’obligations légales.

Il est interdit d’utiliser la messagerie pour :

Le harcèlement ;
Les menaces ;
Les insultes ;
Le spam ;
Les escroqueries ;
L’usurpation d’identité ;
Les sollicitations frauduleuses ;
La diffusion de contenus illicites.

Les messages ;
